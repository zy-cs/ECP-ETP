# ECP-ETP

国网 ECP 2.0 页面的浏览器端展示增强脚本（Tampermonkey 油猴脚本）。

针对「开标记录」没有导出按钮，无法下载。本脚本把明细一次性铺到一页上，并支持一键复制成可直接粘进 Excel 的表格文本。

> 纯浏览器本地展示增强：只读页面数据，不提交、不修改任何服务端内容，不绕过任何权限校验。

---

## 功能

- **单页全显**：优先通过页面的 DevExtreme 组件实例把分页大小调整为 300 条/页，让表格原生渲染全部行；拿不到组件实例时，自动改为逐页收集全部明细并在页面上注入一张完整表格。收集完成后停止遍历，不会持续扫描页面。
- **一键复制全部明细**：输出制表符分隔（TSV）文本，第一行固定是原网页表头，粘到 Excel / WPS 直接分列。
- **诊断信息**：一键复制运行环境信息，便于反馈问题。
- **保留原页面结构**：不隐藏原网格，原网页的分页条仍然可见可点，随时可以对照。
- **单例守卫**：同一页面只注入一条工具条，不会出现两条重叠。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展（Edge / Chrome 均可）。
2. 点击下面的地址，Tampermonkey 会弹出安装页，点「安装」：

   <https://raw.githubusercontent.com/zy-cs/ECP-ETP/main/ecp_openbid_onepage.user.js>
3. 打开 ECP 页面并刷新，页面顶部会出现工具条。

如果 raw 地址访问不稳定，可改用 CDN 镜像地址安装（内容相同，可能有缓存延迟）：

```
https://cdn.jsdelivr.net/gh/zy-cs/ECP-ETP@main/ecp_openbid_onepage.user.js
https://ghproxy.net/https://raw.githubusercontent.com/zy-cs/ECP-ETP/main/ecp_openbid_onepage.user.js
```

## 使用

进入开标记录页面，脚本会在表格上方插入一条工具条，自动识别表格并开始收集明细。

| 界面元素            | 作用                                     |
| --------------- | -------------------------------------- |
| 状态文字            | 显示当前进度：正在识别表格 / 已单页全显 N 行 / 已设 300 条每页 |
| 复制全部明细（含表头 TSV） | 把已收集的全部明细复制到剪贴板，第一行是表头                 |
| 诊断信息            | 复制浏览器版本、页面结构等排查信息                      |
| 原网页分页           | 显示识别的原有分页信息，原分页条仍保留在页面上                |

复制完成后工具条会提示「已复制 N 行 × M 列」，直接到 Excel 里 Ctrl+V 即可分列。

若页面还没加载完表格，工具条会提示暂未识别到开标记录表格，等表格渲染完成后会自动生效。

## 版本与自动更新

脚本通过本仓库的 `main` 分支自动更新，升级地址写在脚本头部：

```
@updateURL    https://raw.githubusercontent.com/zy-cs/ECP-ETP/main/ecp_openbid_onepage.user.js
@downloadURL  https://raw.githubusercontent.com/zy-cs/ECP-ETP/main/ecp_openbid_onepage.user.js
```

升级规则：

- Tampermonkey 只在**远端 `@version` 大于本地**时才升级，改了代码但没改版本号不会触发。
- 版本号只写在 `@version` 里，不写进 `@name`，否则会被识别成另一个脚本。
- 升级后需要刷新 ECP 页面（建议 Ctrl+F5）才会生效。

提示「没有可用更新」通常意味着你已是最新版本；如果确认远端有新版本却升不动，见下方常见问题。

## 常见问题

**页面上出现两条工具条**  
同一脚本装了两份。到 Tampermonkey 管理面板删掉多余的，只保留一条。

**复制出来的行数少于页面显示的数量**  
页面可能仍在加载或分页尚未收集完，等状态栏显示「已单页全显 N 行」再复制。

**点了复制没反应**  
浏览器剪贴板权限受限，或页面尚未获得焦点。点一下页面空白处再试。

**提示发现新版本，但更新失败**  
多数是 `@downloadURL` 失效或网络抖动。可直接用上面的安装地址重新安装一次。

**更新成功但页面行为没变**  
强制刷新页面（Ctrl+F5）；若仍无变化，检查 Tampermonkey 里是否有两份同名脚本在同时运行。
